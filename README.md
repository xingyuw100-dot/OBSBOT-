# OBSBOT GitHub Pages Dashboard

## 功能
- OBSBOT AI Camera 产品矩阵展示
- 产品价格筛选
- 产品搜索
- 产品定位/竞品/用户/卖点展示
- 纯 HTML + CSS + JavaScript，无需服务器

## GitHub Pages 部署

1. 创建 GitHub Repository
2. 上传：
   - index.html
   - style.css
   - script.js
   - README.md
3. Settings → Pages
4. Source选择 main branch
5. 保存后访问生成的网址

## 数据来源

Dashboard基于OBSBOT产品矩阵JSON生成。
